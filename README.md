# 🚀 CS Core Engineering

A 60-day intensive engineering roadmap focused on computer science fundamentals, systems programming, core infrastructure.

---

## 🎯 Objectives
- **Core Fundamentals:** Master low-level programming, memory management, and clean architecture.
- **Hands-on Engineering:** Build production-ready CLI tools, custom data structures, and a deployed backend capstone.
- **Professional Discipline:** Maintain strict version control standards (Conventional Commits) and clean code architecture.

---

## 🛠️ Tech Stack & Core Competencies
- **Languages:** Python, C, Bash, SQL
- **Systems & OS:** Memory Management (Pointers, Dynamic Allocation), Processes, Concurrency
- **Software Engineering:** Data Structures, Algorithms, REST APIs, Git/GitHub, Docker Basics
